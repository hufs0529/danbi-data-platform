# C05 CI/CD (GitHub Actions + OIDC)

## 목표

PR 하나가 머지되기 전에 코드·인프라·보안·비용이 자동으로 검사되고, 배포는 승인된 사람만 수동으로 실행한다.

## 산출물

| 경로 | 내용 |
| --- | --- |
| `.github/workflows/ci.yml` | python(ruff·pytest), terraform(fmt·validate·test 전 루트), checkov, 바뀐 스택 plan(OIDC 읽기 역할), infracost 코멘트 |
| `.github/workflows/deploy.yml` | 수동 실행: 스택 선택 → plan → apply/destroy. environment `dev` 승인 필요, 같은 스택 동시 실행 금지 |
| `scripts/tf_validate_all.sh` | 로컬·CI 공용 Terraform 검사 |
| `scripts/changed_stacks.py` | 바뀐 파일 → plan 할 스택(모듈 변경은 사용하는 스택 전부) |
| `.checkov.yaml` | 건너뛰는 검사와 이유 |

## 흐름

```
task/P1-04 브랜치 push → PR
   ├─ ci: python / terraform / checkov / plan(바뀐 스택) / infracost
   └─ 리뷰 → Squash and merge → main
main 에서 Actions › deploy 실행 (stack=p1-20-streaming, action=apply)
   └─ environment dev 승인 → plan 요약 → apply
```

## GitHub 설정

| 종류 | 이름 | 값 |
| --- | --- | --- |
| 저장소 변수 | `AWS_PLAN_ROLE_ARN` | bootstrap 출력 |
| 저장소 변수 | `TF_STATE_BUCKET`, `TF_STATE_KMS_KEY_ARN` | bootstrap 출력 |
| environment `dev` 변수 | `AWS_APPLY_ROLE_ARN` | bootstrap 출력 |
| environment `dev` 보호 규칙 | Required reviewers | 본인 |
| 시크릿(선택) | `INFRACOST_API_KEY` | infracost 무료 키 |
| 브랜치 보호 | `main` | ci 통과 필수, squash merge만 허용 |

## 검증

- 일부러 `terraform fmt`가 깨진 PR을 올려 terraform 잡이 실패하는지 본다.
- `deploy`를 action=plan으로 실행해 승인 요청이 뜨는지 본다.

## 완료 기준

- 정상 PR에서 모든 잡이 초록이고, 바뀐 스택의 plan 요약이 잡 요약에 남는다.
