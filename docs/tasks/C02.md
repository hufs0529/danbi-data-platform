# C02 Terraform 부트스트랩 (state, GitHub OIDC, 예산)

## 목표

이후 모든 스택이 공유할 원격 state, 키 없는 CI 배포, 비용 안전장치를 먼저 만든다.

## 산출물

| 리소스 | 설정 | 이유 |
| --- | --- | --- |
| S3 `danbi-dev-tfstate-<계정>` | KMS 암호화, 버전 관리, 퍼블릭 차단, TLS 강제, 이전 버전 90일 보관 | state에는 비밀번호·ARN이 들어간다. 버전 관리로 state 손상 시 복구 |
| 잠금 | S3 네이티브 잠금(`use_lockfile = true`) | Terraform 1.10+. DynamoDB 잠금 테이블이 더는 필요 없다 |
| OIDC 제공자 | `token.actions.githubusercontent.com` | GitHub Actions가 단기 자격증명을 받는다 |
| `danbi-dev-gha-plan` | ReadOnlyAccess + state 읽기/쓰기, PR·main에서만 | PR마다 plan |
| `danbi-dev-gha-apply` | Admin + 허용 리전 밖 거부, GitHub environment `dev`에서만 | 승인자가 있는 환경에서만 apply |
| 예산 2개 | 프로젝트 태그 예산(50·80·100%, 예측 100%), 계정 전체 예산(80%) | 실습 계정 비용 사고 방지 |

## 적용

```bash
cd infra/bootstrap
terraform init
terraform apply -var="github_repo=<owner>/danbi-data-platform" -var="alert_email=<you@example.com>"
terraform output -raw backend_hcl > ../backend.hcl
```

GitHub 설정:

1. 저장소 변수 `AWS_PLAN_ROLE_ARN` = `plan_role_arn`
2. Environment `dev` 생성 → 필수 승인자(본인) 지정 → 변수 `AWS_APPLY_ROLE_ARN` = `apply_role_arn`
3. Billing 콘솔에서 비용 할당 태그 `project` 활성화(활성화 전까지는 계정 전체 예산이 알린다)

## 검증

- `aws s3api get-bucket-versioning --bucket <state 버킷>` → `Enabled`
- PR을 열어 plan 잡이 OIDC로 역할을 가정하는지 Actions 로그에서 확인
- 다른 리전(us-west-2)에 리소스를 만드는 apply가 `DenyOutsideAllowedRegions`로 거부되는지 확인

## 완료 기준

- 로컬 `make init STACK=10-network`가 원격 state로 초기화된다.
- 예산 알림 구독 확인 메일을 수락했다.
