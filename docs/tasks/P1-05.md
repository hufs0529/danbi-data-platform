# P1-05 레이크하우스 저장소·카탈로그와 데이터 계약

## 목표

Bronze·Silver·Gold 를 담을 S3·Glue·Athena 를 만들고, **데이터 계약(YAML)을 단일 원본**으로 정해 Silver DDL·수집 시점 PII 정책·Silver 매핑을 모두 계약에서 생성한다(FR-10).

## 산출물

| 경로 | 내용 |
| --- | --- |
| `infra/stacks/p1-30-lakehouse` | 버킷 5개(landing·bronze·silver·gold·athena, 모두 KMS), Glue DB 6개(bronze·silver·ops·gold·gold_audit·rt), Athena 워크그룹 4개(엔지니어·파이프라인·분석가·재무, 스캔 상한·결과 위치 강제) |
| `contracts/p1/silver/*.yaml` | Silver 16개 데이터셋 계약(그레인, 갱신 방식, 파티션, 보존 클래스, SLA, 컬럼별 분류·변환) |
| `contracts/registry.py` | 계약 로더·구조 검증, `pii_policy()`(Flink), `athena_ddl()`, `silver_columns()` |
| `p1/lakehouse/ddl/*.sql` | ops(마이그레이션·워터마크·스키마 드리프트), bronze(cdc_events·domain_events·clicks·정산 파일·정산 라인) |
| `p1/lakehouse/migrate.py` | 손으로 쓴 DDL(체크섬 추적) + 계약 기반 Silver(CREATE / ADD COLUMNS / 비호환 거부 / 분류 대기) |
| `libs/danbi_common/athena.py` | Athena 실행·대기·결과 페이지 처리 |

## 설계 포인트

- **Bronze 는 JSON 변경 로그.** 소스 DDL 이 바뀌어도 Bronze 는 깨지지 않는다. 해석은 계약을 따르는 Silver 가 맡는다.
- **Bronze 부터 평문 PII 가 없다.** 계약의 `token:`/`encrypt:`/`mask:`/`generalize:` 는 수집 시점(Flink)에 적용된다. 일반화만 있고 치환이 없는 필드(birth_date)는 자동으로 drop 이 붙어 원문이 남지 않는다.
- **정렬 키 `change_seq`.** MERGE 는 도착 순서가 아니라 binlog 위치·LSN 순서로 최신을 고른다.
- **Iceberg 버킷에 S3 수명 주기 만료 금지.** 메타데이터가 가리키는 파일이 사라져 테이블이 깨진다. 보존은 DELETE + 스냅샷 만료 + 고아 파일 정리로 한다. 이전 버전만 7일 뒤 정리.
- **스키마 변경(S-C1).** 새 컬럼은 `ADD COLUMNS` 로 자동 반영, 타입 변경·삭제는 거부. Silver 잡이 발견한 계약 밖 컬럼은 `ops.schema_drift` 에 '분류 대기'로 남고, 분류 전에는 분석가 열 필터에 없다(P1-12).
- **워크그룹 강제 설정.** 사람이 결과 위치를 바꿔 다른 버킷으로 내보낼 수 없고, 분석가는 쿼리당 10GB 를 넘게 스캔할 수 없다.

## 적용

```bash
make init STACK=p1-30-lakehouse && make plan STACK=p1-30-lakehouse && make apply STACK=p1-30-lakehouse
python -m p1.lakehouse.migrate plan     # engineer 역할 자격증명
python -m p1.lakehouse.migrate apply
```

## 검증

```sql
SHOW TABLES IN bronze;   -- cdc_events, domain_events, clicks, pg_settlement_files, pg_settlement_lines
SHOW TABLES IN silver;   -- 계약 16개(pg_settlement 포함)
SELECT * FROM "silver"."orders$partitions" LIMIT 1;  -- Iceberg 메타 테이블
```

## 완료 기준

- `migrate plan` 이 변경 없음을 출력한다.
- 계약에 컬럼을 추가하면 `~ ALTER TABLE ... ADD COLUMNS`, 타입을 바꾸면 `!` 오류가 나온다(테스트로 고정).
