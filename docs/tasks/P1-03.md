# P1-03 MSK(IAM 인증)·Schema Registry·토픽 as code

## 목표

이벤트 버스를 만들고, "누가 어떤 토픽을 어떤 스키마로 쓸 수 있나"를 코드로 고정한다.

## 산출물

| 경로 | 내용 |
| --- | --- |
| `infra/stacks/p1-20-streaming` | MSK Provisioned 3.9.x(KRaft) kafka.t3.small×2, 데이터 서브넷, IAM 인증만(9098), TLS·저장 암호화, 브로커 로그. Schema Registry ECS 서비스(`schema-registry.danbi.internal:8081`), 운영 도구 태스크(`stream-admin`) |
| `p1/streaming/topics.yaml`, `topics.py` | 토픽 as code: plan/apply, 파티션 감소 거부, PII 토픽 보존 ≤ 72h 린트, 관리 밖 토픽 표시 |
| `p1/streaming/schema_registry/admin.py` | 호환성 규칙(전역 BACKWARD, 클릭 FULL_TRANSITIVE), check 통과 시에만 register |
| `p1/streaming/schema_registry/Dockerfile` | cp-schema-registry + aws-msk-iam-auth |
| `infra/envs/paused/p1-20-streaming.tfvars` | `msk_enabled=false` (클러스터 삭제) |

## 설계 포인트

- **브로커 2대의 한계를 숨기지 않는다.** `min.insync.replicas=1` 이라 리더만 받은 쓰기는 디스크 장애 시 잃을 수 있다. 운영은 3대 + 2 (ADR AWS-04).
- **auto.create.topics.enable=false.** 오타 토픽이 조용히 생기는 사고를 막는다. 토픽은 `topics.yaml` PR 로만 생긴다.
- **PII 토픽 보존 48~72h.** 파기 SLO(72h) 안에서 원문이 사라지게 한다. 오래 남는 원본은 토큰화된 Bronze 다.
- **커넥터 오프셋 토픽 `connect.offsets.cdc`(compact).** MSK Connect 기본 오프셋 토픽은 커넥터마다 새로 생겨서, 커넥터를 지우고 만들면 처음부터 다시 읽는다. 이름을 고정해 이어받게 한다(P1-04).
- **스키마 등록 권한 분리.** 애플리케이션은 `auto.register.schemas=false`. 등록은 `make schemas SR=register`(호환성 검사 통과 시)만.
- **클릭 이벤트는 FULL_TRANSITIVE.** 구버전 앱이 몇 달 동안 섞여 보내므로 앞뒤 모두 호환이어야 한다.
- **일시 정지 = 재스냅샷.** `make pause` 는 클러스터를 지운다. 재개 후 Debezium 이 처음부터 읽고 Silver MERGE 가 중복을 흡수한다 — 멱등성 설계를 실제로 검증하는 기회로 쓴다.

## 적용

```bash
docker buildx build --platform linux/arm64 -t $ECR/danbi-dev/schema-registry:7.9.2-iam --push p1/streaming/schema_registry
make init STACK=p1-20-streaming && make plan STACK=p1-20-streaming && make apply STACK=p1-20-streaming  # MSK 생성 20~30분
make topics ACTION=plan && make topics ACTION=apply
make schemas SR=config && make schemas SR=register
```

## 검증

```bash
aws kafka describe-cluster-v2 --cluster-arn $(aws ssm get-parameter --name /danbi/dev/p1/streaming/cluster_arn --query Parameter.Value --output text) \
  --query 'ClusterInfo.Provisioned.ClientAuthentication'
make topics ACTION=plan        # "no changes"
make schemas SR=list           # clicks.raw-value
```

## 완료 기준

- `topics plan` 이 변경 없음, 생성기 `make gen-start` 후 clicks.raw 에 메시지가 쌓인다.
- 필드를 기본값 없이 추가한 스키마로 `SR=check` 를 돌리면 FAIL 로 끝난다.
