# P1-15 장애 훈련(F-01~F-10)·런북·포스트모템

## 목표

장애를 '절차'로 다룬다. 훈련마다 주입·기대 동작·수용 기준·검증·복구·증빙이 정해져 있고, 모든 알림이 런북으로 연결된다. 훈련 결과는 포스트모템으로 남긴다.

## 산출물

| 경로 | 내용 |
| --- | --- |
| `p1/drills/catalog.py` | 훈련 10개: 주입 명령, 기대 동작, 수용 기준, 검증 SQL, 복구, 증빙, 런북 |
| `p1/drills/run.py` | `list` · `show` · `verify`(Athena 로 검증 SQL 실행·결과 JSON) · `postmortem`(초안) |
| `docs/runbooks/` | 런북 17개: 증상 → 영향 → 확인 순서(명령) → 조치(경우별 표) → 에스컬레이션 → 사후 |
| `docs/postmortems/` | 템플릿 + F-01 예시(측정 전 목표값임을 명시) |
| 테스트 | 훈련 10개 완비, **코드·알람·DAG 가 가리키는 런북이 모두 존재**(깨진 링크 0), 런북 구조 |

## 훈련 일정 제안(배포 후)

| 주차 | 훈련 | 같이 확인할 것 |
| --- | --- | --- |
| 1 | F-01, F-04 | 알림 도착 시간, 런북 첫 명령까지 걸린 시간 |
| 2 | F-02, F-06 | 대사 리포트 원인 코드 |
| 3 | F-05, F-08, F-09 | 속보치 vs 확정치, WAP 차단, 상태 복원 |
| 4 | F-03, F-07, F-10 | 4시간 복구, 작은 파일, 점검 리포트 |

## 사용

```bash
python -m p1.drills.run show F-03
python -m p1.drills.run verify F-01 > docs/postmortems/evidence/F-01-$(date +%F).json
python -m p1.drills.run postmortem F-01 > docs/postmortems/$(date +%F)-F01.md
```

## 완료 기준

- 10개 훈련을 한 번씩 수행하고 포스트모템 10개(수용 기준 대비 결과, 액션 아이템)를 남긴다.
