# C01 저장소 골격과 작업 규칙

## 목표

모든 이후 태스크가 같은 규칙(브랜치, 커밋, PR, 검증 명령)으로 쌓이게 한다.

## 산출물

| 경로 | 내용 |
| --- | --- |
| `README.md` | 프로젝트 개요, 적용 순서, 빠른 시작 |
| `Makefile` | `init/plan/apply/destroy STACK=…`, `pause/resume`, `lint/test/tf-fmt/tf-validate` |
| `pyproject.toml` | ruff·pytest 설정, 개발 의존성 |
| `.pre-commit-config.yaml` | ruff, terraform fmt, gitleaks, 커밋 메시지 검사 |
| `docs/conventions.md` | 태스크 ID, 브랜치, 커밋 메시지, 인프라 변경 규칙 |
| `scripts/check_commit_msg.py` | 커밋 메시지에 태스크 ID가 있는지 검사 |
| `infra/envs/dev/common.tfvars` | 모든 스택이 공유하는 변수 |

## 적용

```bash
pip install -e '.[dev]' pre-commit
pre-commit install --hook-type pre-commit --hook-type commit-msg
```

## 검증

```bash
make lint test
echo "VPC 추가" > /tmp/msg && python scripts/check_commit_msg.py /tmp/msg   # 실패해야 한다
```

## 완료 기준

- 잘못된 커밋 메시지가 훅에서 막힌다.
- `make test`가 통과한다.
