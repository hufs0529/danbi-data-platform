# C06 플랫폼(ECS·ECR·운영 접속)과 공통 라이브러리

## 목표

P1·P2의 컨테이너 워크로드가 공유할 실행 기반과, 두 프로젝트가 같은 방식으로 개인정보를 다루게 하는 공용 코드를 만든다.

## 산출물

| 경로 | 내용 |
| --- | --- |
| `infra/stacks/30-platform` | ECS 클러스터(Fargate·Spot), 공용 실행 역할, ECR(태그 불변·스캔·보관 10개), Cloud Map `danbi.internal`, 운영 EC2(SSM 전용, IMDSv2) |
| `infra/modules/ecs_service` | Fargate 태스크 정의 + 선택적 서비스(서비스 디스커버리, ALB, 서킷 브레이커, ECS Exec) |
| `libs/danbi_common/pii/tokenize.py` | 결정적 토큰화(HMAC-SHA256, 종류·키 버전 포함, 정규화) |
| `libs/danbi_common/pii/detect.py` | 한국어 PII 탐지·마스킹: 주민번호(날짜·체크섬), 전화, 이메일, 카드(Luhn), 계좌(은행 문맥), 여권, 운전면허, 도로명 주소, 문맥 기반 이름 |
| `libs/danbi_common/logs.py` | JSON 로깅 + PII 마스킹 필터 |
| `libs/danbi_common/aws.py` | 비밀·파라미터 TTL 캐시 조회 |

## 적용

```bash
make init STACK=30-platform && make plan STACK=30-platform && make apply STACK=30-platform
# RDS 등에 붙을 때: 운영 EC2 경유 포트 포워딩
aws ssm start-session --target <ops_instance_id> \
  --document-name AWS-StartPortForwardingSessionToRemoteHost \
  --parameters host=<rds-endpoint>,portNumber=3306,localPortNumber=13306
```

## 검증

```bash
pytest libs -q     # 토큰화 7건, 탐지·마스킹 10건
aws ecr describe-repositories --query 'repositories[].imageTagMutability'   # 모두 IMMUTABLE
```

## 완료 기준

- 단위 테스트가 통과하고, 운영 EC2에 SSM 세션으로 접속된다(인바운드 규칙 0개).
